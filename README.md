# BOSS Summit
A biannual gathering of Indian BOSS developers, designers, and educators, organized by Bitshala. [Read More](https://bitshala.org/boss/)

## What It Is
The BOSS Summit is designed for all Bitcoin Open Source developers, designers, and educators. It is a multi-day summit featuring key individuals from the Indian Bitcoin ecosystem.

The event takes place at a private, invite-only location.

The attendees consist exclusively of professionals working on various Bitcoin-related projects, including Bitcoin, Lightning, Nostr, eCash, and more.

The summit aims to foster in-depth discussions and brainstorming sessions on the most challenging engineering, product, design, and educational problems in the Bitcoin Open Source Software (BOSS) ecosystem.

## Who It Is For
- If you are a professional builder in the BOSS ecosystem in India, this summit is for you.
- If you are part of the Bitshala Fellowship Program, this summit is for you.
- If you have successfully graduated from SOB and are exploring further opportunities in Bitcoin, this summit is for you.
- If you are curious, not yet a professional, but can engage with day-long, intense technical to semi-technical topics, this summit is for you.

Admission rights are reserved by Bitshala and will be granted based on space availability.
